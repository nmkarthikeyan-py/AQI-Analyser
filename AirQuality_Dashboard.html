Data quality and limits

  • 108 of 1,943 readings (5.6%) had no value and were excluded. No duplicates, bad timestamps or impossible coordinates were found.
  • Single time point. This is one hourly snapshot, so it shows today's pattern, not seasonality. Run the refresh script on a schedule to build a history.
  • Indicative AQI. The official method uses 24-hour averages; this feed gives the latest averaging window. CO is excluded because its unit is not documented. A station needs 3 pollutants including PM2.5 or PM10 (6 stations did not qualify).
  • Partial coverage. Only 17 states appear, so do not read this as a national ranking. Delhi alone has 59 stations, which pulls up any all-station average.
